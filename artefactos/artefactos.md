# Fundamentos de Java para Principiantes
## Resumen del Curso
Este curso de 1 hora introduce a estudiantes de secundaria a los fundamentos de la programación con Java, incluyendo
programación orientada a objetos. **¡No requiere descargas!** Solo abre tu navegador web.
**Duración total**: ~60 minutos
**Público Objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación
**Prerrequisitos**: Ninguno
**Herramientas necesarias**: **¡Solo tu navegador web!** (Chrome, Firefox, Safari, Edge)
**📂 Repositorio de Código Fuente**: [https://github.com/Energix-Course-Java/informe-fundamentals-course-Energix](https://github.com/Energix-Course-Java/informe-fundamentals-course-Energix)

### Lección 1: Tu Primer Héroe

**Descripción**

Esta lección introduce los conceptos básicos de variables y tipos de datos en Java. Los estudiantes aprenden a crear y mostrar un personaje con atributos básicos como nombre, vida, ataque y nivel.

**Código (Main.java)**

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("=== CREACION DE HEROE ===");
        
        String nombre = "Warrior";
        int vida = 100;
        int ataque = 15;
        int nivel = 1;
        
        System.out.println("Nombre: " + nombre);
        System.out.println("Vida: " + vida);
        System.out.println("Ataque: " + ataque);
        System.out.println("Nivel: " + nivel);
        
        System.out.println("\nEncontraste un tesoro!");
        nivel = nivel + 1;
        vida = vida + 20;
        ataque = ataque + 5;
        
        System.out.println("\nSUBISTE DE NIVEL!");
        System.out.println("Nivel: " + nivel);
        System.out.println("Vida: " + vida);
        System.out.println("Ataque: " + ataque);
    }
}
```

**Conceptos clave**
- Declaración de variables (`String`, `int`)
- Operaciones aritméticas básicas
- Concatenación de strings
- Impresión en consola con `System.out.println()`

### Lección 2: Tu Primera Batalla 

**Enlace:** https://replit.com/@ikerbarturen659/Leccion-2#src/main/java/Main.java

**Descripción**

Esta lección muestra estructuras de decisión (if-else) y entrada por consola mediante la clase `Scanner`. Se presenta un pequeño juego de combate donde el jugador elige entre atacar o defender.

**Código (Main.java)**

```java
import java.util.Scanner;

public class Main {
  public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    int vidaHeroe = 100;
    int vidaMonstruo = 75;

    System.out.println("¡Bienvenido a la batalla!");
    System.out.println("Un Goblin salvaje ha aparecido");

    System.out.println("\n¿Que haras?");
    System.out.println("1. Atacar");
    System.out.println("2. Defender");
    System.out.print("Elige: ");
    int opcion = sc.nextInt();

    if (opcion == 1) {
      System.out.println("¡Has atacado al Goblin!");
      vidaMonstruo = vidaMonstruo - 105;
      System.out.println("Vida del Goblin: " + vidaMonstruo);
      if (vidaMonstruo <= 0) {
        System.out.println("¡Has derrotado al Goblin!");
      } else {
        System.out.println("El Goblin te ha atacado");
        vidaHeroe = vidaHeroe - 15;
        System.out.println("Vida del Heroe: " + vidaHeroe);
      }
    } else {
      System.out.println("Te has defendido");
      System.out.println("Recibes menos daño");
    }
  }
}
```

**Notas y sugerencias**

- El código usa valores fijos de daño y vida; para prácticas adicionales se puede parametrizar (por ejemplo: daño mínimo/máximo aleatorio).
- Actualmente el ataque causa 105 puntos de daño al monstruo (valor muy alto). Considerar ajustar para equilibrar la jugabilidad.
- Añadir validación de entrada (por ejemplo, manejo de entradas no numéricas) para evitar excepciones en tiempo de ejecución.

### Lección 3: Múltiples Enemigos

**Descripción**

Esta lección enseña el uso de bucles (`for` y `while`) y arrays. Los estudiantes crean una mazmorra con múltiples enemigos y aprenden a iterar sobre estructuras de datos.

**Código (Main.java)**

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        
        int vidaHeroe = 100;
        String[] enemigos = {"Murcielago", "Goblin", "Zombie"};
        
        System.out.println("=== MAZMORRA ===");
        System.out.println("Hay " + enemigos.length + " enemigos\n");
        
        for (int i = 0; i < enemigos.length; i++) {
            System.out.println("--- Batalla " + (i+1) + " ---");
            System.out.println("Enemigo: " + enemigos[i]);
            
            int vidaEnemigo = 30;
            
            while (vidaEnemigo > 0 && vidaHeroe > 0) {
                System.out.println("\n1. Atacar");
                System.out.print("Accion: ");
                int accion = sc.nextInt();
                
                if (accion == 1) {
                    vidaEnemigo = vidaEnemigo - 20;
                    System.out.println("Atacaste! Vida enemigo: " + vidaEnemigo);
                    
                    if (vidaEnemigo > 0) {
                        vidaHeroe = vidaHeroe - 10;
                        System.out.println("Te atacaron! Tu vida: " + vidaHeroe);
                    }
                }
            }
            
            if (vidaHeroe <= 0) {
                System.out.println("\nGAME OVER");
                return;
            }
            System.out.println("Enemigo derrotado!\n");
        }
        
        System.out.println("COMPLETASTE LA MAZMORRA!");
    }
}
```

**Conceptos clave**
- Arrays de strings (`String[] enemigos`)
- Bucle `for` para iteración
- Bucle `while` para combate
- Propiedad `length` de arrays
- Control de flujo con `return`

### Lección 4: Organiza tu Código

**Descripción**

Esta lección introduce los métodos en Java para organizar y reutilizar código. Los estudiantes aprenden a crear funciones sin parámetros, con parámetros y que retornan valores, implementando un sistema de aventura RPG más estructurado.

**Código (Main.java)**

```java
import java.util.Scanner;

public class Main {
    static int vida = 100;
    static int oro = 0;
    
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        
        mostrarBienvenida();
        
        boolean jugando = true;
        while (jugando) {
            mostrarMenu();
            int opcion = sc.nextInt();
            
            if (opcion == 1) {
                explorar();
            } else if (opcion == 2) {
                mostrarEstado();
            } else if (opcion == 3) {
                descansar();
            } else if (opcion == 4) {
                jugando = false;
            }
        }
        
        System.out.println("Gracias por jugar!");
    }
    
    public static void mostrarBienvenida() {
        System.out.println("=== AVENTURA RPG ===\n");
    }
    
    public static void mostrarMenu() {
        System.out.println("\n1. Explorar");
        System.out.println("2. Ver estado");
        System.out.println("3. Descansar");
        System.out.println("4. Salir");
        System.out.print("Elige: ");
    }
    
    public static void explorar() {
        System.out.println("\nEncontraste un enemigo!");
        vida = vida - 15;
        oro = oro + 20;
        System.out.println("Ganaste 20 oro!");
        System.out.println("Vida: " + vida);
    }
    
    public static void mostrarEstado() {
        System.out.println("\n=== ESTADO ===");
        System.out.println("Vida: " + vida);
        System.out.println("Oro: " + oro);
    }
    
    public static void descansar() {
        vida = vida + 30;
        if (vida > 100) vida = 100;
        System.out.println("\nDescansaste. Vida: " + vida);
    }
}
```

**Conceptos clave**
- Métodos sin parámetros (`mostrarBienvenida()`, `mostrarMenu()`)
- Variables estáticas (`static int vida`, `static int oro`)
- Organización del código en funciones
- Bucle principal del juego
- Validación de límites (`if (vida > 100) vida = 100`)

### Lección 5: Programación Orientada a Objetos

**Descripción**

Esta lección introduce los conceptos fundamentales de POO en Java: clases, objetos, constructores y métodos. Los estudiantes crean clases `Heroe` y `Enemigo` para un sistema de combate más realista.

**Código (Main.java)**

```java
class Heroe {
    String nombre;
    int vida;
    int ataque;
    
    public Heroe(String n, int v, int a) {
        nombre = n;
        vida = v;
        ataque = a;
    }
    
    public void mostrar() {
        System.out.println("\n=== " + nombre + " ===");
        System.out.println("Vida: " + vida);
        System.out.println("Ataque: " + ataque);
    }
    
    public void atacar(Enemigo enemigo) {
        System.out.println(nombre + " ataca!");
        enemigo.recibirDano(ataque);
    }
}

class Enemigo {
    String nombre;
    int vida;
    
    public Enemigo(String n, int v) {
        nombre = n;
        vida = v;
    }
    
    public void recibirDano(int dano) {
        vida = vida - dano;
        System.out.println(nombre + " recibe " + dano + " de dano");
        System.out.println("Vida enemigo: " + vida);
    }
    
    public boolean estaVivo() {
        return vida > 0;
    }
}

public class Main {
    public static void main(String[] args) {
        Heroe jugador = new Heroe("Warrior", 100, 25);
        Enemigo goblin = new Enemigo("Goblin", 50);
        
        jugador.mostrar();
        
        System.out.println("\n=== COMBATE ===");
        while (goblin.estaVivo()) {
            jugador.atacar(goblin);
        }
        
        System.out.println("\nVICTORIA!");
    }
}
```

**Conceptos clave**
- Definición de clases (`class Heroe`, `class Enemigo`)
- Constructores con parámetros
- Atributos de clase (`nombre`, `vida`, `ataque`)
- Métodos que retornan valores (`boolean estaVivo()`)
- Interacción entre objetos (`jugador.atacar(goblin)`)

### Proyecto Final: Juego Completo

**Descripción**

El proyecto final integra todos los conceptos aprendidos en el curso: variables, estructuras de control, métodos, arrays y POO. Los estudiantes crean un juego RPG completo con múltiples niveles, sistema de experiencia y progresión del personaje.

**Código (Main.java)**

```java
import java.util.Scanner;

class Personaje {
    String nombre;
    int vida;
    int ataque;
    
    public Personaje(String n, int v, int a) {
        nombre = n;
        vida = v;
        ataque = a;
    }
    
    public void atacar(Personaje otro) {
        otro.vida = otro.vida - ataque;
        System.out.println(nombre + " ataca a " + otro.nombre);
        System.out.println("Dano: " + ataque);
    }
    
    public boolean estaVivo() {
        return vida > 0;
    }
}

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        
        System.out.println("=== JUEGO RPG ===");
        System.out.print("Nombre de tu heroe: ");
        String nombre = sc.nextLine();
        
        Personaje heroe = new Personaje(nombre, 100, 20);
        int nivel = 1;
        int oro = 0;
        
        String[] enemigos = {"Murcielago", "Goblin", "Zombie", "Dragon"};
        
        for (int i = 0; i < enemigos.length; i++) {
            System.out.println("\n--- Nivel " + (i+1) + " ---");
            Personaje enemigo = new Personaje(enemigos[i], 40 + (i*10), 10 + (i*3));
            
            System.out.println("Aparecio: " + enemigo.nombre);
            
            while (heroe.estaVivo() && enemigo.estaVivo()) {
                System.out.println("\nTu vida: " + heroe.vida);
                System.out.println("Vida enemigo: " + enemigo.vida);
                System.out.println("\n1. Atacar");
                System.out.println("2. Huir");
                System.out.print("Accion: ");
                int accion = sc.nextInt();
                
                if (accion == 1) {
                    heroe.atacar(enemigo);
                    
                    if (enemigo.estaVivo()) {
                        enemigo.atacar(heroe);
                    }
                } else {
                    System.out.println("Huiste!");
                    break;
                }
            }
            
            if (!heroe.estaVivo()) {
                System.out.println("\nGAME OVER");
                System.out.println("Llegaste al nivel " + (i+1));
                return;
            }
            
            if (!enemigo.estaVivo()) {
                System.out.println("\nVICTORIA!");
                oro = oro + 25;
                nivel = nivel + 1;
                heroe.vida = heroe.vida + 20;
                heroe.ataque = heroe.ataque + 5;
                System.out.println("Oro: " + oro);
                System.out.println("Subiste de nivel!");
            }
        }
        
        System.out.println("\n=== JUEGO COMPLETADO ===");
        System.out.println("Nivel final: " + nivel);
        System.out.println("Oro total: " + oro);
    }
}
```

**Características del proyecto**
- **Personalización**: El jugador puede elegir el nombre de su héroe
- **Progresión**: Sistema de niveles con mejora de estadísticas
- **Variedad de enemigos**: Cada enemigo tiene estadísticas escaladas
- **Mecánicas de juego**: Opción de atacar o huir
- **Condiciones de victoria/derrota**: Multiple finales posibles

**Conceptos integrados**
- Entrada del usuario (`Scanner`, `nextLine()`, `nextInt()`)
- Clases y objetos (`Personaje`)
- Arrays y bucles (`for`, `while`)
- Lógica de juego compleja
- Escalado dinámico de dificultad (`40 + (i*10)`, `10 + (i*3)`)
